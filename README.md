# 🔗 Link Shortener

Sistema de encurtador de links construído com Python, Docker, Traefik e REST API.

## 📦 Funcionalidades

- Criação de URLs encurtadas
- Redirecionamento baseado em short_code
- Métricas de cliques (IP, user-agent, data/hora)
- Gerenciamento de links via API REST
- Ambiente 100% containerizado com Docker Compose
- Traefik como reverse proxy dinâmico

## 🚀 Executando o Projeto

```bash
docker-compose up --build
